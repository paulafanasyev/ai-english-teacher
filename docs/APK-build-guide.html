Требования и установка

APK нельзя собрать в облачном окружении — нужны JDK, Android SDK и Gradle на вашей машине (Windows, macOS или Linux — любая подойдёт, в отличие от iOS, которому нужен только macOS). Установите три вещи:

  • Node.js 18+ — nodejs.org. Проверка: node -v
  • JDK 17 (именно 17 — требование Capacitor 6 и Android Gradle Plugin 8). Рекомендую Eclipse Temurin 17. Проверка: java -version
  • Android Studio — developer.android.com/studio. Он ставит Android SDK, build-tools, platform-tools и Gradle.

Настройка Android Studio (один раз)

  1. Запустите Android Studio → пройдите мастер первого запуска (он докачает SDK).
  2. Откройте Settings → Languages & Frameworks → Android SDK и убедитесь, что установлены: Android SDK Platform 34, SDK Build-Tools 34, Platform-Tools, SDK Command-line Tools.
  3. Примите лицензии SDK (обязательно, иначе Gradle упадёт):
терминал — принять лицензии SDK
# macOS / Linux
yes | $ANDROID_HOME/cmdline-tools/latest/bin/sdkmanager --licenses

# Windows (PowerShell)
& "$env:ANDROID_HOME\cmdline-tools\latest\bin\sdkmanager.bat" --licenses
💡

Проверка готовности: node -v ≥ 18, java -version → 17.x, а также появилась команда adb version. Если все три отвечают — можно продолжать.

2

Переменные окружения

Gradle должен знать, где лежат JDK и Android SDK. Задайте JAVA_HOME, ANDROID_HOME и добавьте инструменты в PATH.

macOS / Linux — ~/.zshrc или ~/.bashrc
export JAVA_HOME="/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home"  # macOS
# export JAVA_HOME="/usr/lib/jvm/temurin-17-jdk-amd64"                        # Linux

export ANDROID_HOME="$HOME/Library/Android/sdk"   # macOS
# export ANDROID_HOME="$HOME/Android/Sdk"          # Linux

export PATH="$PATH:$ANDROID_HOME/platform-tools:$ANDROID_HOME/cmdline-tools/latest/bin"
Windows — PowerShell (постоянно)
[System.Environment]::SetEnvironmentVariable('JAVA_HOME','C:\Program Files\Eclipse Adoptium\jdk-17','User')
[System.Environment]::SetEnvironmentVariable('ANDROID_HOME',"$env:LOCALAPPDATA\Android\Sdk",'User')
# затем перезапустите терминал
ℹ️

Android Studio обычно сам создаёт файл android/local.properties со строкой sdk.dir=... при первом открытии проекта. Если собираете чисто из терминала и Gradle пишет «SDK location not found» — создайте этот файл вручную (см. раздел «Ошибки»).

3

Инициализация проекта

Capacitor уже добавлен в зависимости проекта (@capacitor/core, @capacitor/android, @capacitor/cli — v6.1), а конфиг apps/web/capacitor.config.json заполнен. Нужно установить зависимости, собрать веб-билд и создать нативный Android-проект.

из корня репозитория
cd apps/web

npm install                 # зависимости, включая Capacitor 6
npm run build               # Vite собирает веб-приложение в apps/web/dist

npx cap add android         # создаёт папку android/ (только один раз)
npx cap sync android        # копирует dist/ в нативный проект + плагины

Что делает каждая команда:

  • npm run build — генерирует статический веб-билд в apps/web/dist (это и есть webDir из конфига).
  • npx cap add android — разворачивает Gradle-проект в папке android/ с вашим appId и иконкой-заглушкой.
  • npx cap sync — переносит свежий dist/ внутрь android/app/src/main/assets/public и подключает плагины. Запускайте его после каждого npm run build.
⚡

В package.json есть готовый скрипт-ярлык: npm run cap:sync = npm run build && npx cap sync. Удобно повторять при каждом изменении кода.

4

Debug-APK — для теста и сайдлоада

Debug-APK не требует ключа подписи (Android подписывает его автоматически debug-ключом) — идеально, чтобы быстро проверить приложение на своём телефоне.

сборка debug-APK
cd android

# macOS / Linux
./gradlew assembleDebug

# Windows
gradlew.bat assembleDebug
📦Готовый файл:  android/app/build/outputs/apk/debug/app-debug.apk

Установка на телефон

  1. Через кабель (adb): включите на телефоне «Отладку по USB», подключите его и выполните команду ниже.
  2. Вручную: перекиньте app-debug.apk на телефон и откройте, разрешив «Установку из неизвестных источников».
установка по кабелю
adb devices                              # убедитесь, что телефон виден
adb install app/build/outputs/apk/debug/app-debug.apk
🖥️

Альтернатива терминалу — открыть проект в Android Studio: npx cap open android (или npm run cap:android), затем нажать ▶ Run с подключённым устройством/эмулятором.

5

Иконки и сплэш-экран

cap sync не генерирует иконки сам. Официальный инструмент @capacitor/assets создаёт все размеры из одной картинки.

генерация иконок и сплэша
# положите исходники в apps/web/resources/
#   icon.png    — 1024×1024 (иконка приложения)
#   splash.png  — 2732×2732 (заставка, по желанию)

npm i -D @capacitor/assets

npx capacitor-assets generate --android \
  --iconBackgroundColor '#7c3aed' \
  --iconBackgroundColorDark '#4c1d95'

После генерации пересоберите и синхронизируйте: npm run build → npx cap sync. Цвета выше совпадают с фирменным фиолетовым приложения (#7c3aed).

6

Ключ подписи (keystore)

Для установки на чужие устройства и публикации в Google Play APK/AAB нужно подписать своим ключом. Создайте keystore один раз и храните его надёжно — потерять его нельзя (без него не выпустить обновления приложения).

создание ключа — keytool входит в JDK
keytool -genkey -v \
  -keystore aet-release.keystore \
  -alias aet \
  -keyalg RSA -keysize 2048 -validity 10000

Команда спросит пароль и данные (имя, организация — можно кратко). Запомните пароль хранилища, alias (aet) и пароль ключа.

🔒

Критично: сделайте резервную копию файла aet-release.keystore и паролей. Никогда не коммитьте его в git — добавьте *.keystore и keystore.properties в .gitignore.

7

Подписанный APK и AAB для Google Play

Подключим ключ к Gradle через файл свойств, чтобы не хранить пароли в коде.

7.1  Файл android/keystore.properties

android/keystore.properties (создать)
storeFile=../../aet-release.keystore
storePassword=ВАШ_ПАРОЛЬ_ХРАНИЛИЩА
keyAlias=aet
keyPassword=ВАШ_ПАРОЛЬ_КЛЮЧА

storeFile — путь к keystore относительно папки android/app. Если положили aet-release.keystore в корень репозитория, то путь ../../aet-release.keystore подходит (можно указать и абсолютный путь).

7.2  Правка android/app/build.gradle

В самом верху файла (до блока android {) добавьте загрузку свойств, а внутри android { — конфиг подписи:

android/app/build.gradle
// --- вверху файла, до "android {" ---
def keystorePropertiesFile = rootProject.file("keystore.properties")
def keystoreProperties = new Properties()
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}

android {
    // ... существующие настройки (compileSdk, defaultConfig и т.д.) ...

    signingConfigs {
        release {
            if (keystorePropertiesFile.exists()) {
                storeFile file(keystoreProperties['storeFile'])
                storePassword keystoreProperties['storePassword']
                keyAlias keystoreProperties['keyAlias']
                keyPassword keystoreProperties['keyPassword']
            }
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
            proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro'
        }
    }
}

7.3  Сборка

подписанный APK (для сайдлоада) и AAB (для Play)
cd android

# Вариант A — подписанный APK (раздать напрямую / установить вручную)
./gradlew assembleRelease
#  → app/build/outputs/apk/release/app-release.apk

# Вариант B — AAB (обязательный формат для Google Play)
./gradlew bundleRelease
#  → app/build/outputs/bundle/release/app-release.aab
✅Проверить подпись:  $ANDROID_HOME/build-tools/34.0.0/apksigner verify --print-certs app-release.apk

7.4  Публикация в Google Play

  1. Зарегистрируйте аккаунт в Google Play Console (разовый взнос $25).
  2. Создайте приложение, заполните карточку (описание, скриншоты, значок 512×512, приватность).
  3. В разделе Production → Create release загрузите app-release.aab.
  4. Рекомендуется включить Play App Signing — Google будет хранить финальный ключ подписи, а вы подписываете загрузочным ключом.
8

Онлайн-режим с вашим сервером (опционально)

По умолчанию APK упаковывает офлайн-демо (все данные — на устройстве, без интернета). Чтобы приложение работало с вашим backend (Node + PostgreSQL: логин по JWT, кабинеты, дневник онлайн) — соберите веб-часть с адресом API и пересинхронизируйте.

сборка в серверном режиме
cd apps/web

VITE_API_URL=https://api.вашдомен.com npm run build
npx cap sync android

# дальше — обычная сборка debug/release из шага 4 или 7
⚠️

Backend должен работать по HTTPS (в конфиге androidScheme: "https", allowMixedContent: false). Настройка сервера и TLS — в DEPLOY.md.

9

Частые ошибки и решения

ОшибкаПричина и решение
SDK location not foundНет пути к SDK. Создайте android/local.properties со строкой sdk.dir=/путь/к/Android/sdk (Windows: sdk.dir=C:\\Users\\Вы\\AppData\\Local\\Android\\Sdk), либо задайте ANDROID_HOME (шаг 2).
Unsupported class file major versionНеверная версия Java. Нужен JDK 17. Проверьте java -version и JAVA_HOME.
You have not accepted the license agreementsНе приняты лицензии SDK. Выполните sdkmanager --licenses (шаг 1).
Failed to find Build Tools revision 34.0.0Не установлены build-tools. Поставьте через SDK Manager в Android Studio или sdkmanager "build-tools;34.0.0".
Белый экран после установкиНе синхронизирован свежий билд. Выполните npm run build && npx cap sync и пересоберите.
adb: no devices foundНа телефоне не включена «Отладка по USB», либо не подтверждён запрос доверия. Проверьте adb devices.
Gradle падает по памяти (OOM)В android/gradle.properties увеличьте org.gradle.jvmargs=-Xmx2048m.
keystore was tampered with, or password was incorrectНеверный пароль/alias в keystore.properties, либо путь storeFile указывает не на тот файл.

Шпаргалка команд

Полный цикл от нуля до подписанного релиза:

всё вместе
# --- разовая настройка ---
cd apps/web
npm install
npm run build
npx cap add android
keytool -genkey -v -keystore aet-release.keystore -alias aet -keyalg RSA -keysize 2048 -validity 10000
# + создать android/keystore.properties и правку build.gradle (шаг 7)

# --- каждая новая сборка ---
cd apps/web
npm run build && npx cap sync android

cd android
./gradlew assembleDebug      # debug APK для теста
./gradlew assembleRelease    # подписанный APK
./gradlew bundleRelease      # AAB для Google Play
РезультатПуть
Debug APKandroid/app/build/outputs/apk/debug/app-debug.apk
Release APKandroid/app/build/outputs/apk/release/app-release.apk
Release AABandroid/app/build/outputs/bundle/release/app-release.aab
📱

Самый быстрый путь на телефон без Android SDK — это PWA: приложение уже содержит manifest.webmanifest + service worker и устанавливается прямо из браузера по HTTPS («Установить приложение»). Подробнее — в MOBILE.md. Capacitor нужен именно для публикации в Google Play.
